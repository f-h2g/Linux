## Installation Steps

1. I prepared a virtual machine on my computer before installing Ubuntu.
2. Then, I downloaded the Ubuntu Linux ISO file from the official website.
3. I selected the ISO file in the virtual machine and completed the Ubuntu installation by following the setup instructions.
4. After the installation, I restarted the virtual machine and checked that Ubuntu was working correctly.
5. Next, I updated the operating system and installed ROS 2 Humble by following the installation guide.
6. Finally, I tested ROS to make sure it was installed successfully.

## Problems I Encountered

- At first, Ubuntu did not work properly on my device, so I had to update the system before continuing the installation.
- Some required packages failed to install on the first attempt, so I repeated the installation process.
- The installation took longer than expected because the system needed additional updates.
- After restarting the system, everything worked correctly, and I was able to complete the ROS installation.

## Result

Ubuntu Linux and ROS 2 Humble were installed successfully after updating the system and completing the installation process. Everything was working correctly.
